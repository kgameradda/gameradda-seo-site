APPLICATION PURPOSE

What is CreatorBoost?

One workspace for the research and channel-management tasks gaming creators repeat every week.

CreatorBoost by Gameradda helps gaming creators understand their YouTube channel, research video opportunities, and organize optimization work before publishing.

A creator can connect a YouTube channel through Google OAuth and use the connected channel data inside the CreatorBoost dashboard. SEO Studio provides keyword and content-research workflows, while the Video Manager and related tools help organize publishing tasks.

GOOGLE DATA & PERMISSIONS

Why CreatorBoost uses Google APIs.

YouTube channel data

When you connect YouTube, CreatorBoost uses authorized Google/YouTube API access to identify your connected channel and retrieve the channel, video and analytics information needed for enabled features.

User-controlled actions

CreatorBoost requests access for specific creator workflows. Actions that can change YouTube content are performed only as part of a feature the creator chooses to use.

Keyword research

SEO Studio is designed to use keyword-research data to provide search-demand, competition and related optimization signals. Provider availability can vary by configuration.

Google Ads Campaign Management

CreatorBoost can use authorized Google Ads API access to support campaign planning, creation, management, and reporting. Campaign actions are initiated by the authorized user through CreatorBoost.

Google API Services User Data Policy

CreatorBoost's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only for the functionality described in the application and privacy policy.
