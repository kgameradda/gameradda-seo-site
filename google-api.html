GOOGLE API DATA USE

How CreatorBoost uses Google APIs

Last updated: August 27, 2026

Why access is requested

CreatorBoost requests Google access when a creator chooses to connect YouTube or use another feature that requires Google data. The purpose is to provide the connected-channel and analytics workflows described on the CreatorBoost homepage.

Data categories

  • Channel identity and channel-level information.
  • Video and Shorts information needed by connected-channel workflows.
  • YouTube Analytics information needed for channel-performance metrics.
  • Keyword-research information when the relevant SEO data provider is enabled.

Use and transfer

CreatorBoost uses Google user data only to provide the requested functionality. It does not sell Google user data or use it for unrelated advertising. Data may be sent to Google's APIs when necessary for an authorized operation.

Limited Use

CreatorBoost's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

User control

Connecting a YouTube account is optional. Users can revoke CreatorBoost's access through their Google Account security settings. For privacy or deletion requests, email support@kgameradda.com.

Least privilege

CreatorBoost is designed to request only the scopes necessary for the enabled feature. The exact scopes shown to a user are determined by the production Google Cloud configuration and the API operations used by the application.
