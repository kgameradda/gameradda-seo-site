# Contributing

Thanks for helping improve CreatorBoost.

## Development rules

1. Do not commit credentials or personal OAuth tokens.
2. Keep Google Ads API calls on the server side.
3. Preserve the paused-first campaign review workflow.
4. Keep public privacy, terms, contact, and Google API disclosure pages synchronized with actual application behavior.
5. Run TypeScript/build checks before submitting changes when the local environment supports them.

## Pull requests

Describe:

- what changed
- why it changed
- affected routes/components
- Google Ads API resources or operations involved
- testing performed
- any required environment variables
