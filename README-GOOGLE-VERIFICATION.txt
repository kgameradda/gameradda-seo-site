BEFORE SUBMITTING TO GOOGLE
----------------------------
1. Upload every file to the root of the GitHub Pages repository.
2. Confirm https://kgameradda.com/ loads publicly in an incognito window.
3. Confirm these URLs load:
   https://kgameradda.com/privacy.html
   https://kgameradda.com/terms.html
   https://kgameradda.com/contact.html
   https://kgameradda.com/google-api.html
4. In Google Cloud OAuth Branding:
   App name: CreatorBoost
   Authorized domain: kgameradda.com
   Homepage: https://kgameradda.com/
   Privacy policy: https://kgameradda.com/privacy.html
   Terms: https://kgameradda.com/terms.html
5. Verify kgameradda.com in Google Search Console using an account that is
   an Owner or Editor of the Google Cloud project.
6. Make sure support@kgameradda.com is a real working mailbox or forwards
   to an inbox you monitor. Do not submit a dead support address.
7. Make sure the scopes in Google Cloud exactly match the scopes actually
   requested by the production app. Request the narrowest scopes necessary.
8. Do NOT upload OAuth client secrets, refresh tokens, API keys, developer
   tokens, or .env files to this website repository.

IMPORTANT
---------
This website is a verification/brand-information site. It does not itself
perform OAuth. The actual OAuth configuration and API behavior remain in
the CreatorBoost application.

The privacy policy describes the Google/YouTube and keyword-research flows
used by the CreatorBoost application. Before submission, review it against
the exact production data flow and scopes in your Cloud project.

Google verification is not guaranteed by a website alone. Google also checks
the Cloud project, authorized domains, OAuth consent-screen information,
requested scopes, branding, and the actual application's behavior.
