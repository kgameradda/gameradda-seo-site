CREATORBOOST BY GAMERADDA

Privacy Policy

Last updated: August 22, 2026

1. Overview

CreatorBoost is a gaming YouTube SEO and keyword research tool operated by Gameradda. This policy explains what information the application accesses, how it is used, and how it is protected.

2. Google services used by CreatorBoost

The application may use Google OAuth to connect a user's YouTube channel when the user chooses the YouTube connection feature. Depending on the enabled feature, the application can access channel and video information needed to identify the user's channel, list videos and Shorts, and perform the requested Shorts-link automation.

The application also uses Google Ads API Keyword Planner functionality for keyword research. Keyword research is performed using the application's Google Ads API account and is not used to manage advertising campaigns for users.

3. How Google user data is used

  • YouTube channel information is used to display the connected channel and operate requested video/Shorts automation.
  • YouTube video information is used to identify Shorts and the latest long-form video for the automation feature.
  • Keyword Planner metrics are used to provide keyword ideas, search demand, competition, CPC, trend information and SEO recommendations.
  • Google data is not sold or used for unrelated advertising purposes.

4. Data sharing

CreatorBoost does not sell Google user data. Google user data is not shared with advertisers or data brokers. Data may be transmitted to Google's APIs when necessary to provide the requested functionality.

5. Credentials and security

OAuth credentials and access tokens are treated as confidential and are used only to perform the Google operations authorized by the user. Users should revoke access from their Google Account if they no longer want CreatorBoost connected.

6. Data retention

The development version is designed to use Google data only for the requested operation and to minimize retention. If persistent storage is introduced in a future production version, this policy will be updated before that feature is made available.

7. Your choices

You can disconnect the YouTube account from CreatorBoost and revoke the application's Google access through your Google Account security settings. You can also stop using the application at any time.

8. Changes

If CreatorBoost changes how it accesses, uses, stores or shares Google user data, this policy will be updated.

9. Contact

For questions about this privacy policy or CreatorBoost, contact the support email associated with the Google Cloud project used by the application.
